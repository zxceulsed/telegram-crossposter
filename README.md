# Telegram Crossposter

Telegram-бот для автоматического кросспостинга публикаций из Telegram в сообщества ВКонтакте и Одноклассников.

Проект позволяет настроить несколько связок «Telegram-источник → VK/OK» и автоматически публиковать сообщения с заданной задержкой.

## Возможности

* Автоматический перенос публикаций из Telegram в VK
* Автоматический перенос публикаций в Одноклассники
* Настройка нескольких источников и целевых групп
* Индивидуальная задержка перед публикацией от 1 до 24 часов
* Хранение настроек подключений в базе данных
* Управление подключениями через Telegram-бота
* Добавление новых связок без изменения исходного кода
* Просмотр существующих связок
* Удаление подключений
* обработка фотографий, видео и документов;
* автоматические повторные попытки при ошибках API;
* логирование публикаций;
* статистика успешных и неуспешных публикаций;
* Ограничение административных команд по Telegram ID

## Как это работает

Администратор один раз создаёт связку между Telegram-источником и целевыми площадками.

Например:

```text
Telegram-канал
     │
     ▼
Telegram Crossposter
     │
     ├── задержка 2 часа
     │
     ├──────────► VK
     │
     └──────────► Одноклассники
```

После публикации сообщения в Telegram бот:

1. Проверяет, настроена ли связка для источника.
2. Получает текст сообщения или подпись к медиа.
3. Ожидает заданную задержку.
4. Отправляет публикацию в VK.
5. Отправляет публикацию в Одноклассники.
6. Сообщает результат публикации.

Задержка задаётся в часах и может составлять от 1 до 24 часов.

## Администрирование

Доступ к административным функциям имеют только пользователи, указанные в конфигурации приложения.

### Добавление подключения

```text
/add_connection
```

После выполнения команды бот последовательно запрашивает:

* ID Telegram-источника
* API ключ VK
* ID группы VK
* ACCESS TOKEN Одноклассников
* GROUP ID Одноклассников
* APPLICATION KEY
* SESSION SECRET KEY
* задержку перед публикацией

После завершения настройки создаётся новая связка.

### Просмотр подключений

```text
/show_connections
```

Показывает зарегистрированные связки, идентификаторы источников и целевых групп, а также установленную задержку.

### Удаление подключения

```text
/delete_connection
```

Позволяет удалить существующую связку по её ID.

## Архитектура

```text
telegram-crossposter/
├── handlers/
│   ├── admin.py
│   └── repost.py
│
├── services/
│   ├── db.py
│   ├── vk_service.py
│   └── ok_service.py
│
├── utils/
│
├── main.py
├── states.py
└── requirements.txt
```

### `handlers`

Содержит Telegram-обработчики.

`admin.py` отвечает за административные команды и настройку подключений.

`repost.py` обрабатывает входящие сообщения из Telegram и запускает процесс публикации.

### `services`

Слой сервисов отвечает за взаимодействие с внешними API и базой данных.

### `states.py`

Для настройки подключения используется FSM `aiogram`.

Последовательно обрабатываются отдельные состояния для ввода параметров Telegram, VK, Одноклассников и задержки публикации.

## Отложенная публикация

Задержка реализована асинхронно через `asyncio.sleep()`.

Например, при установленной задержке `2` часа публикация будет выполнена через:

```python
await asyncio.sleep(delay * 3600)
```

Это позволяет не блокировать event loop обычным синхронным ожиданием.

## Технические решения

### FSM для настройки

Настройка подключения разбита на последовательные состояния. Благодаря этому администратору не требуется передавать все параметры одной командой.

### Асинхронная обработка

Бот работает на `asyncio` и `aiogram`, а задержка реализована без блокирующего `sleep`.

### Отдельные сервисы для API

Интеграции с VK и Одноклассниками вынесены в отдельные сервисы, что упрощает поддержку и дальнейшее расширение проекта.

### Хранение конфигураций

Настройки связок сохраняются в базе данных, поэтому после перезапуска приложения их не требуется создавать заново.
